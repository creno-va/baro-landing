# BARO landing

Public beta preparation page for the personal money loan MVP. It collects no case input, registration data or analytics events.

Publishing this preparation page does not approve the legal policies or open the BARO beta. Keep the first CTA, planned features and legal notice consistent with [BARO readiness](https://github.com/creno-va/baro/milestone/4). Approved policy URLs and versions require separate legal/business approval before public beta.

Install pinned dependencies with `bun ci`, install Chromium with `bunx playwright install chromium`, and run `bun run check`. The check verifies WCAG A/AA, keyboard navigation, narrow screens, 200% zoom, the status CTA and absence of case-entry forms/tracking and unsupported product claims. GitHub Pages serves `main` at the repository root.
